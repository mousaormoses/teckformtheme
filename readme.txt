A complete agency and business theme built for Elementor, with 25 widgets and a one-click demo.

== Description ==

Teckform keeps markup and styles to a minimum so Elementor layouts render edge to edge.
It supports a custom logo, primary and footer menus, featured images, and Elementor Pro
Theme Builder locations (header, footer, single, archive).

Design your own header and footer with Elementor in Header & Footer, and choose
where each one shows: the entire site, the front page, or specific pages.
Headers can be sticky and transparent over the page. Section templates power
popups and mega menus.

Content types for Services, Projects (with categories), Team and Testimonials
feed the widgets. Colors and fonts follow Elementor's Global Colors and Fonts,
dark mode is built in, and the theme is translation-ready and works right to left.

Appearance > Import Demo installs the complete "Teckform Studio" agency site in one click.

It adds 25 widgets to Elementor, grouped at the top of the panel:

Teckform Sections:

* Hero - six layouts: centered, split, full background image or video, product screenshot, animated headline with stats, and split with form.
* Posts Grid - posts, services or projects in cards, with category filter and page numbers.
* Portfolio Grid - projects with a category filter bar.
* Team - members from the Team content type or typed in, with social links.
* Testimonials Carousel - sliding reviews with ratings.
* Logo Carousel - scrolling or grid client logos.
* Pricing Table - plans with a monthly/yearly switch and a "most popular" badge.
* FAQ - accordion that also adds FAQ structured data for Google.
* Process / Timeline - steps or a timeline, horizontal or vertical.
* Call to Action - a banner with buttons.
* Countdown - to a date, or a per-visitor "evergreen" countdown.
* Contact Form - any fields, email delivery, spam protection, and every message saved in WordPress.
* Newsletter - saves subscribers in WordPress (CSV export) or sends them to Mailchimp and similar services.
* Login / Register - login and sign-up forms for visitors.

Teckform Header & Footer:

* Site Logo, Nav Menu (with mega menus), Search, Copyright, Dark Mode Toggle.

Teckform Elements:

* Animated Headline, Flip Box, Before / After, Image Hotspots, Popup, Feature Box.

== Installation ==

1. In your WordPress dashboard go to Appearance > Themes > Add New > Upload Theme.
2. Choose teckform.zip and click Install Now, then Activate.
3. Install and activate the free Elementor plugin when prompted.
4. Optional: Appearance > Import Demo to install the demo site.

== Frequently Asked Questions ==

= Emails from the Contact Form don't arrive =
Many hosts don't deliver email sent by WordPress reliably. Install an SMTP plugin
(for example WP Mail SMTP). Every message is also saved under Messages in the dashboard.

= Forms say "expired" on a cached site =
Exclude pages with Teckform forms from page caching.
