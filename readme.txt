A lightweight starter theme built for Elementor.

== Description ==

Teckform keeps markup and styles to a minimum so Elementor layouts render edge to edge.
It supports a custom logo, primary and footer menus, featured images, and Elementor Pro
Theme Builder locations (header, footer, single, archive).

Design your own header and footer with Elementor in Header & Footer, and choose
where each one shows: the entire site, the front page, or specific pages.
Headers can be sticky and transparent over the page.

It also adds its own widgets to Elementor, grouped at the top of the panel under
Teckform Sections, Teckform Header & Footer, and Teckform Elements:

* Hero - the first section of a page in six layouts: centered, split, full background image or video, product screenshot, animated headline with stats, and split with form.
* Site Logo - the site logo, with an optional second logo once the header is scrolled.
* Nav Menu - dropdown menu on desktop, slide-in menu on tablet and mobile.
* Search - search icon that opens a full-screen search, or an inline search box.
* Copyright - footer text with the current year filled in automatically.
* Dark Mode Toggle - lets visitors switch between light and dark mode.
* Feature Box - icon, title, description and optional link.

== Installation ==

1. In your WordPress dashboard go to Appearance > Themes > Add New > Upload Theme.
2. Choose teckform.zip and click Install Now, then Activate.
3. Install and activate the free Elementor plugin when prompted.
